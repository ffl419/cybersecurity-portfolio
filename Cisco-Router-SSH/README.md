# Cisco Router Secure SSH Configuration

## Project Overview

In this lab, I configured a Cisco router for secure remote administration using SSH. A client device connected to the router through a network switch.

## Objective

The objective was to configure and verify secure remote access to a Cisco router using SSH instead of an unencrypted remote-access protocol.

## Network Topology

Computer → Cisco Switch → Cisco Router

## Technologies Used

- Cisco Packet Tracer
- Cisco IOS
- IPv4
- SSH Version 2
- RSA keys
- VTY lines
- Local user authentication

## Tasks Completed

- Connected the client, switch, and router
- Assigned IP addressing
- Configured the router hostname and domain name
- Created a local user account
- Generated RSA keys
- Enabled SSH Version 2
- Configured the VTY lines for SSH access
- Tested connectivity with ping
- Successfully authenticated to the router using SSH

## Result

The SSH connection was successful. I was able to securely access and manage the Cisco router from the client device through the network switch.

## Skills Demonstrated

- Cisco IOS configuration
- Secure remote administration
- IPv4 addressing
- Network connectivity testing
- SSH configuration
- Basic network troubleshooting

## What I Learned

This project helped me understand how SSH provides secure remote access to network devices. I also gained hands-on experience with Cisco IOS commands, RSA key generation, VTY configuration, user authentication, and connectivity testing.
